# Hi3516CV610 基于fmcv100控制器的 Nand Flash 器件适配指南(HY035-9901-0011, HY073-9901-0003)

## 1 编译BSP

输入以下命令，先完整编译一次bsp。

```bash
make LIB_TYPE=musl CHIP=hi3516cv610 DEBUG=1 BOOT_MEDIA=spi_nand all -j
```

> **为什么要先完整编译一次？**
>
> 610 SDK 首次编译时会自动解压 Linux 和 U-Boot 源码包，并应用 SDK 自带的补丁。如果在此之前手动解压或修改源码，可能导致补丁应用失败，进而引发编译错误。因此，需要先完成一次完整编译，等待源码解压和补丁应用结束后，再进行 Nand Flash 器件适配。

## 2 linux 适配

1. 修改`open_source/linux/linux-5.10.y/drivers/mtd/nand/fmc100/fmc_spi_nand_ids.c`

在`fmc_spi_nand_flash_table`结构体中的最前面，插入以下内容并保存：
```c
	{
		.name      = "HY035-9901-0011",
		.id        = {0xe5, 0xf2},
		.id_len    = 2,
		.chipsize  = _256M,
		.erasesize = _128K,
		.pagesize  = _2K,
		.oobsize   = 128,
		.badblock_pos = BBP_FIRST_PAGE,
		.read      = {
			&read_quad(1, INFINITE, 104), /* 104MHz */
			0
		},
		.write     = {
			&write_quad(0, 256, 104), /* 104MHz */
			0
		},
		.erase     = {
			&erase_sector_128k(0, _128K, 104), /* 104MHz */
			0
		},
		.driver    = &spi_driver_general,
	},

	{
		.name      = "HY073-9901-0003",
		.id        = {0x0B, 0x12},
		.id_len    = 2,
		.chipsize  = _256M,
		.erasesize = _128K,
		.pagesize  = _2K,
		.oobsize   = 128,
		.badblock_pos = BBP_FIRST_PAGE,
		.read      = {
			&read_quad_addr(1, INFINITE, 104), /* 104MHz */
			0
		},
		.write     = {
			&write_quad(0, 256, 104), /* 104MHz */
			0
		},
		.erase     = {
			&erase_sector_128k(0, _128K, 104), /* 104MHz */
			0
		},
		.driver    = &spi_driver_general,
	},
```

2. 删除以下两个文件：

```bash
open_source/linux/linux-5.10.y/drivers/mtd/nand/fmc100/fmc_spi_nand_ids.o
open_source/linux/linux-5.10.y/drivers/mtd/nand/fmc100/fmc100_spi_general.o
```
